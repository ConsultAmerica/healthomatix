# Healthomatix V1.8 — Clinical AI Governance Report

**Date:** 2026-10-29

## 1. AI capability inventory (implemented in repo)

| Feature | Intended use | Clinical impact | Human oversight | Provider |
|---|---|---|---|---|
| Document / lab extraction | Draft structured fields from uploads | High if trusted blindly | Clinician verify queue | Fake OCR/LLM (default) |
| Pre-visit / consultation AI | Summaries for clinicians | Medium | Review before acting | Fake / optional |
| AI medical scribe | Ambient note drafts | High | Must sign/edit manually | Fake / optional |
| Note quality checks | Suggestions | Medium | Clinician decides | Fake |
| Messaging assistance | Draft replies | Medium–High | Send requires human | Fake |
| Patient education | General education content | Medium | Non-diagnostic framing | Fake |
| Care coordination tasks | Suggested tasks | Medium | Approval gates | App + Fake |
| Coding / RCM AI | Coding suggestions | Financial / compliance | Human approve charges/claims | Fake |

Unsupported modules must not be claimed as production clinical AI.

## 2. Risk classification

Higher risk: extraction, scribe, messaging, coding — require stronger eval + oversight.  
Lower risk: non-diagnostic education drafts with clear disclaimers.

## 3. Model governance record (current)

| Field | Value |
|---|---|
| Provider | Fake adapters in `backend/app/integrations` / intelligence ports |
| Model / prompt version | Sandbox fixtures — not production models |
| Approval status | **Not approved for real PHI** |
| Known limitations | Hallucination, grounding failure, unsafe wording possible with live LLMs |

## 4. Safety evaluation (synthetic)

Automated suites cover authorization and workflow gates (V1.3–V1.5). Dedicated clinical hallucination benchmarks against live models are **not** complete in this increment.

Mandatory rules already encoded:

- AI must not diagnose, prescribe, auto-sign notes, auto-merge patients, place lab orders, or approve imports/claims.

## 5. Change control

Before production model/prompt change: record change → evaluate → regression → safety metrics → clinical risk review → approval → controlled release → monitor → rollback plan.
