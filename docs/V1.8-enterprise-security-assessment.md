# Healthomatix V1.8 — Enterprise Security Assessment

**Date:** 2026-10-29

## Authentication

- OIDC bearer validation: HTTPS issuer/JWKS, audience, `exp`/`iat`/`iss`/`sub`/`aud`, RS256/ES256 (`auth.py`).
- Web: authorization-code + PKCE; AES-GCM HttpOnly session; CSRF header + Origin check on proxy.
- Demo auth: HMAC-compared shared secret; refused when `HEALTHOMATIX_ENV=production`.
- Platform admin MFA: optional/required via `REQUIRE_MFA_FOR_PLATFORM_ADMIN` checking `amr`/`acr`.
- Gaps: phishing-resistant MFA for all privileged clinic roles; account recovery is IdP-owned; brute-force at IdP/edge.

## Authorization

- Server-side `require_membership` / `require_role` / `require_clinic_patient` / consent / entitlements.
- Frontend route gates are UX only — API enforces access.
- Platform admin allowlist separate from tenant roles.

## Tenant isolation

- Tenant ID in path never trusted without membership.
- Cross-tenant requests return non-disclosing 404.
- V1.8 added isolation coverage for integrations + support tickets.

## API security

- Pydantic strict models; ApiError envelope without stack traces to clients.
- CORS allowlist; security headers middleware; process-local rate limit.
- Document MIME sniffing, size caps, path-safe keys, Fake malware gate.
- Gaps: distributed rate limit, full CSP on web, SSRF review for future webhooks, WAF.

## Dependency / infrastructure

- CI workflow runs pytest + advisory pip-audit/npm audit.
- No committed production credentials found in `.env.example` (placeholders only).
- Gaps: secret manager, container image scanning SBOM enforcement, network segmentation IaC.

## Open vulnerabilities / findings

1. Secrets in env files — migrate to managed secrets (R-02).
2. Fake malware in non-prod — production fail-closed until vendor (R-03).
3. Rate limiter not multi-instance safe (R-04).
4. Dependency audit non-blocking until SLA approved (R-13).

**Conclusion:** Controls are suitable for **synthetic / staging** use. **Not** sufficient alone for uncontrolled real-PHI production without closing critical risks.
