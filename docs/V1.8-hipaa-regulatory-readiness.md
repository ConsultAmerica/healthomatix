# Healthomatix HIPAA & Regulatory Readiness Assessment

**Date:** 2026-10-29  
**Scope:** Intended U.S. healthcare SaaS deployment (controlled launch)  
**Disclaimer:** This is an engineering evidence package. It is **not** a HIPAA certification, legal opinion, or organizational compliance approval. HIPAA does not provide a general government-issued software certification.

## 1. Applicable obligations (intended)

- If Healthomatix creates, receives, maintains, or transmits PHI on behalf of covered entities → likely **business associate** role (confirm with counsel).
- Safeguards: administrative, physical (cloud/hosting), technical.
- Breach notification, BAAs, subcontractors (AI, telehealth, storage, IdP).

## 2. Safeguard assessment (summary)

| Area | Status | Evidence | Gap |
|---|---|---|---|
| Access control | Partial | OIDC, RBAC, tenant isolation, consent | Privileged MFA incomplete for all roles |
| Audit controls | Partial | `AuditEvent`, exchange audit | SIEM retention / review cadence |
| Integrity | Partial | SHA-256 docs, provenance, idempotent imports | Formal integrity monitoring |
| Authentication | Partial | OIDC + PKCE session cookie | Production IdP MFA policy |
| Transmission security | Partial | HTTPS assumed; HSTS header in production setting | TLS config / cert ops not IaC-proven |
| Workforce security | Gap | Support tickets exist | Training, sanctions, access reviews |
| Contingency | Gap | DR runbook drafted | Restore drill not executed |
| BAAs | Gap | Checklist only | Executed BAAs required before PHI |

## 3. Privacy & BAA notes

- Demo/synthetic mode must remain free of real PHI.
- Patient export exists (authorized Bundle) — aligns with access concepts but does not satisfy all Right of Access operational requirements alone.
- Subprocessors (IdP, cloud DB, object storage, AI, video, payments) must be inventoried and contracted.

## 4. Required policies (organizational)

- Security management / risk analysis ownership
- Access management & joiner-mover-leaver
- Incident response & breach notification
- Contingency / backup
- Device/media (workforce endpoints)
- Data retention & disposal
- Sanction & training
